Learn-Engineering is a student-developed Progressive Web Application (PWA) created to provide a centralized and organized platform for accessing academic resources.

The platform is designed to simplify the distribution and accessibility of study materials by organizing resources according to engineering branch and semester.

The system is built using modern web technologies and cloud-based infrastructure:

  • Frontend: Responsive HTML5, Vanilla JavaScript, and modular CSS architecture.
  • Backend & Authentication: Supabase PostgreSQL Database, Row Level Security (RLS), and User Authentication.
  • Storage & Delivery: Cloudflare Workers interfacing securely with Backblaze B2 Object Storage.
  • Application: Progressive Web Application (PWA) designed for accessibility across modern devices.
